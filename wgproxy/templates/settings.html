Upstream proxy

SOCKS5 proxy of the outer VPN client (Throne / sing-box / Clash: usually 127.0.0.1:2080). Every WireGuard endpoint and the endpoint-hostname DNS server dial through it, so all tunnel traffic stays on loopback and is never captured by the outer VPN's TUN. Leave the host empty for direct mode (tunnels then follow the host routing table). The upstream must support UDP (SOCKS5 UDP ASSOCIATE).

    Proxy credentials

    Required by every local proxy (SOCKS5 and HTTP). Generated at install; changing them restarts all tunnels.

    Ports

    New proxies get the lowest free port in this range. Existing assignments never move unless their port is unavailable at start-up (only that proxy moves). Per-proxy overrides are below.
